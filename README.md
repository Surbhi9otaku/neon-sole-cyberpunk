# NEON//SOLE — Cyberpunk Sneaker UI

A responsive React + Vite landing page for a cyberpunk sneaker brand concept.

## Run locally
1. Install Node.js (18+ recommended).
2. Extract this folder and open a terminal inside it.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Build for deployment
`npm run build`

The site includes responsive navigation, a countdown timer, product cards, add-to-cart interactions, and toast feedback. Product photography uses remote Unsplash URLs; internet access is required for those images. Replace these with approved assets if the event requires all assets to be local.
